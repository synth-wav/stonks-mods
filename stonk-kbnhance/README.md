# Enhanced Keyboard Controls (`stonk-kbnhance`)

**Trade without touching the mouse.** Enhanced Keyboard Controls lets you work the whole Exchange from the keyboard: switch tabs, pick rows, buy, sell and confirm. It also adds hotkeys for game speed.

## Features

- **Tab between Exchange tabs**: Stocks, Shorts, Portfolio and Commodities.
- **Pick rows with the arrow keys.** A highlight marks the selected row without blurring its text, even with the CRT effect on. Going past the end of a page moves to the next or previous page.
- **Buy and sell from the keyboard.** Hold the key to keep buying or selling, with the same speed-up as holding the mouse button.
- **Quantity multiplier on every tab.** W now works on Stocks and Shorts too, not just Commodities.
- **Confirm with Enter**, open company details with **I**, and bulk-buy with **B**.
- **Browse the Charts with the arrow keys.** Highlight one company's line at a time, the same as hovering it with the mouse.
- **Solo a stock.** Hide every other line and see the highlighted one on a chart zoomed to its own price range, so small ups and downs are easy to see.
- **Game speed hotkeys**: speed time up or slow it down from the main screen, including a **turbo** speed beyond the normal fast-forward.
- **Plays by the game's rules.** Every key does exactly what the matching button does: the same purchase limits, trading time, fees and confirmation.

## Controls

### In the Exchange

| Key | Action |
| --- | --- |
| **Tab** | Next tab (Stocks → Shorts → Portfolio → Commodities) |
| **↑ / ↓** | Select a row |
| **← / →** | Previous / next page |
| **+ / −** | Buy / sell the selected row (hold to repeat). `=` and the numpad +/− work too |
| **W** | Change the quantity multiplier (x1, x2, x5 … x500) |
| **Enter** | Confirm the deal |
| **I** | Open the selected company's details |
| **B** | Bulk buy the selected stock |
| **Esc** | Close the Exchange |

### In Charts

Works on the company and commodity charts.

| Key | Action |
| --- | --- |
| **↑ / ↓** | Highlight the next / previous line |
| **S** | Solo the highlighted line on a zoomed chart. Press again to bring the rest back |

### Anywhere else

| Key | Action |
| --- | --- |
| **.** | Speed up: pause → normal → fast → turbo |
| **,** | Slow down |
| **Space** | Pause / resume |

## Good to know

- **Orders aren't final until you press Enter.** +/− set up the deal. Enter (or the deal button) completes it, and closing the Exchange cancels anything unconfirmed, the same as with the mouse.
- **Switching to the Stocks or Shorts tab clears unconfirmed orders**, the same as clicking the tab. Confirm first.
- **Turbo** is twice as fast as the normal fast-forward. An extra arrow lights up in the top bar while it's on.
- **Soloing is only a view.** The y-axis of the solo chart starts near the stock's lowest price instead of at 0, which is why the shape stands out. Pressing S again, or leaving Charts, brings back exactly the lines you had shown before.
- **The mouse still works.** Mix and match freely.
- **Safe for your saves.** The mod doesn't store anything in your save file, so you can turn it on or off at any time.

## Installation

1. Copy [`stonk-kbnhance.meow`](stonk-kbnhance.meow) into the game's `mods` folder.
2. Start the game and enable **Enhanced Keyboard Controls** in the Mods menu.
3. Open the Exchange and press **Tab**.
