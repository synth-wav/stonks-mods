# stonks-mods

Mods for [STONKS-9800](https://store.steampowered.com/search/?term=STONKS-9800), the retro stock-market simulator. The mods are written in [Catspeak](https://www.katsaii.com/catspeak-lang) (`.meow` files), the scripting language the game's built-in mod loader uses.

## Mods

| Mod | Dev name | What it does |
| --- | --- | --- |
| [Enhanced Keyboard Controls](stonk-kbnhance/) | `stonk-kbnhance` | Run the whole Exchange from the keyboard |
| [Morally Lucky](stonk-morallylucky/) | `stonk-morallylucky` | Normative-ethics dilemmas (VE, UTL, DNT) where luck decides the fallout, and great philosophers who seek you out. Mature themes |

## Installing a mod

1. Copy the mod's `.meow` file into the game's `mods` folder
   (Steam: right-click STONKS-9800 → *Manage* → *Browse local files* → `mods`).
2. Start the game and enable the mod in the **Mods** menu.
