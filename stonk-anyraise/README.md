# Any Raise (`stonk-anyraise`)

[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3817196874)

**Raise what you want in the secret poker games.** The table only offers two raise sizes and All-in. Any Raise adds a control that lets you pick any amount in between.

## Features

- **Any raise size**, from the minimum legal raise up to your whole stack.
- **Pot-sized raise in one click** with the **Pot** button or **P**.
- **Keyboard and mouse wheel.** Adjust the amount without moving the mouse to the buttons.
- **Plays by the game's rules.** A raise goes through the same code as the game's own Raise buttons, so the pot, minimum re-raise and opponents' replies all work the usual way. Raising your whole stack counts as an All-in, so side pots still work.

## Controls

When it's your turn, a row appears above the Pot readout: **[−] [6. Raise 120] [+] [Pot]**.

| Key | Action |
| --- | --- |
| **− / +** | Lower / raise the amount (hold to repeat). `=` and the numpad −/+ work too |
| **Mouse wheel** | Same as − / + |
| **Shift** | Steps of 50 instead of 5 |
| **P** | Pot-sized raise |
| **6** | Make the raise |

The game's own buttons and keys **1–5** still work as before.

## Good to know

- **The amount resets each turn** to one step above the game's bigger Raise button.
- **Nobody has bet yet?** The control makes a bet instead of a raise, the same as the game's Bet 5 / Bet 10 buttons.
- **Hidden when it can't help**: if your stack can't cover more than the minimum raise, only the game's All-in remains.
- **Safe for your saves.** The mod doesn't store anything in your save file, so you can turn it on or off at any time.

## Installation

1. Copy [`stonk-anyraise.meow`](stonk-anyraise.meow) into the game's `mods` folder.
2. Start the game and enable **Any Raise** in the Mods menu.
3. Sit down at a secret poker game.
